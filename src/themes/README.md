# Built-in artwork

柚子（capybara）与月白（moon）为本仓库原创 SVG 图形，由 `scripts/generate-pet.mjs` 生成，不复制第三方角色。

- 192 × 208 逻辑帧，6 列 × 7 行，共 42 帧。
- 行顺序：idle / thinking / working / juggling / sleeping / drag / happy。
- 同时提供 SVG 图集、无损 WebP 图集与原生主题清单。
- 运行 `npm run assets` 可重复生成；生产端不需要 sharp。
- Apache-2.0，沿用仓库 LICENSE。

# 水豚噜噜 · Playground 示例

本目录的 `spritesheet.webp` 来自用户提供的本地 Clawd-on-desk 主题
`codex-pet-capybara-lulu/assets/spritesheet.webp`，原样复制，未重新压缩。
角色名称与描述来自原主题：**水豚噜噜**，暖黄色圆润水豚，戴小南瓜帽并背绿色斜挎小包。

- WebP：1536 × 1872，透明背景，1,529,066 bytes（约 1.53 MB）。
- Codex V1：8 列 × 9 行，单帧 192 × 208；使用核心已有的 Codex 帧映射与逐帧时序。
- `pet.json` 是去除本机路径后的便携清单；展示适配与点击时序见 `../../themes.ts`。
- 直接引用图集，避免桌面版 SVG 包装中的相对外链图片在浏览器 `<img>` 内被阻止。
- 仅用于 Playground 展示；不复制进插件 `dist/`，也不包含在 npm 发布文件中。
  插件默认主题仍为内置原创「柚子」，预览页可切回该主题。
